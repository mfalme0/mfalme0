## principles
```text
● ● ●   cat -n ~/principles.md
```

```text
 1  automate the second occurrence.
    the first time is research, the second is a bug report.

 2  make failure loud and boring.
    alert early, page rarely, never let a silent failure live.

 3  prefer the reversible.
    a flag beats a rollback beats a migration you can't undo.

 4  delete before you optimise.
    the fastest code is the code you removed.

 5  document the why, not the what.
    the commit already says what changed.
```
